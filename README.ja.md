# sts2_matchmaker

Slay the Spire 2 のマルチプレイに**マッチング(自動検索/ホスト)、再募集、キック/BAN**機能を追加するMODです。

> このMODはゲームプレイに影響を与えないMODとして登録されているため(`mod_manifest.json` の `affects_gameplay: false`)、**このMODを入れていない相手ともマルチプレイに支障なく遊べます。** 招待リンクから直接参加するなど、既存の方法はMODの有無に関係なくそのまま動作します。ただし「マッチング(自動検索)」機能自体は、お互いにこのMODを入れている場合のみ使えます。

## 使い方

### マッチング

メインメニュー→マルチプレイ画面に新しく追加された **「マッチング」** ボタンを押すと、マッチング設定画面が開きます。

- **コミュニティ名**: 同じグループとだけ集まりたいときに使用。空欄なら誰とでもマッチングします。
- **言語**: 特定の言語のユーザーとだけマッチング。「指定なし」を選ぶとフィルターなし。
- **ランの種類**: スタンダード / デイリー / カスタム。
- **アセンションレベル**: 希望するアセンションレベル。「指定なし」を選ぶと、自分がクリアした最高アセンション以下の部屋なら何でもマッチングします。
- **人数**: 目標人数。メインのマッチングポップアップでのみ「指定なし」を選択可能(ホストになる可能性もあるため、実際の部屋定員とは別に動作します)。
- **ホストを許可**: チェックを外すと参加のみ試み、相手が見つからなければホストにはならずに待機し続けます。

右下のチェック(✓)ボタンでマッチングを開始します。条件に合う部屋が見つかれば自動参加し、見つからず「ホストを許可」がオンなら自動でホストになります。

すでにホスト中のロビーでも、キャラクターカード横の **「マッチング」** ボタンから同じ設定画面を開き、空いている枠を検索に公開できます。同じ画面の **「リンクをコピー」** ボタンで、この部屋に直接参加できるリンクをクリップボードにコピーして他の人に渡すこともできます。

### 再募集

マルチプレイのランが異常終了した後、再び集まるための機能です。

- **ホスト**: マルチプレイメニューの(元からある) **「セーブからホスト」** ボタンを押すと、自動的に検索可能な状態で開きます。参加者に招待リンクを別途送る必要はありません。
- **参加者**: マッチング設定画面の **「待機」** ボタンを押しておくと、ホストがセーブを再度開いた瞬間に自動で見つけて接続します。元々そのランにいた人だけが実際に参加できます(セーブにいない人は自動的に拒否されます)。
- 元のメンバーが再び揃うと自動的にレディ(出発準備完了)状態になり、待機なしですぐに再開します。

### キック / BAN

ロビーで各プレイヤーカードの横にボタンが表示されます。

- **ホスト**: 「キック」(ただ退出させる)/「BAN」(即座に退出させてBANリストに登録、以降そのユーザーとはマッチングで会わなくなる)
- **ゲスト**: 「BAN登録」(今すぐ追い出すことはできないが、以降自分のマッチングからそのユーザーを除外)
- チャレンジ履歴(過去のラン記録)画面からも、過去の仲間をBAN登録できます。
- ホストにキックされた際に表示されるポップアップにも、そのままそのホストをBAN登録できるボタンが追加で表示されます。

BANリストはマッチング設定画面の **「BANリスト」** タブで確認・解除できます。このリストは完全にローカル(自分のみ)の設定で、マッチング検索時にBANした相手がホストの部屋はそもそも表示されません。

### MOD情報

マッチング設定画面の **「MOD情報」** タブで、現在インストールされているMODの一覧を確認できます。ここに表示されるのはインストール済みMOD全体ではなく、**マルチプレイのマッチングに影響する(ゲームプレイ関連の)MODのみ**です。マッチングは常に、このMODリストが完全に一致する相手とのみ成立します(オフにできない必須条件です)。
