# sts2_matchmaker

Slay the Spire 2 멀티플레이에 **매칭(자동 검색/호스트), 재모집, 킥/밴** 기능을 추가하는 모드입니다.

> 게임플레이에 영향을 주지 않는 모드로 등록되어 있어(`mod_manifest.json`의 `affects_gameplay: false`), **이 모드를 설치 안 한 사람과 멀티플레이해도 아무 지장 없습니다.** 초대 링크로 직접 참가하는 등 기존 방식은 모드 유무와 상관없이 그대로 동작합니다. 다만 "매칭(자동 검색)" 기능 자체는 서로 이 모드를 설치했을 때만 서로를 찾을 수 있어요.

## 사용법

### 매칭

메인 메뉴 → 멀티플레이 화면에 새로 생긴 **"매칭"** 버튼을 누르면 매칭 설정 창이 뜹니다.

- **커뮤니티명**: 같은 그룹끼리만 모이고 싶을 때 사용. 비워두면 아무나와 매칭됨.
- **언어**: 특정 언어 사용자와만 매칭. "언어 무관" 선택 시 필터 없음.
- **런 종류**: 스탠다드 / 데일리 / 커스텀.
- **승천 단계**: 원하는 승천 레벨. "무관" 선택 시 내가 클리어한 최고 승천 이하 아무 방이나 매칭.
- **인원 수**: 목표 인원. 메인 매칭 창에서만 "무관" 선택 가능(호스트가 될 수도 있는 상황이라 실제 방 정원과 별개로 동작).
- **호스트 허용**: 체크 해제 시 참가만 시도하고, 상대를 못 찾으면 계속 대기(호스트가 되지 않음).

우측 하단 체크(✓) 버튼으로 매칭을 시작합니다. 조건에 맞는 방을 찾으면 자동 참가하고, 못 찾았는데 "호스트 허용"이 켜져 있으면 자동으로 방을 엽니다.

이미 호스팅 중인 로비에서도 캐릭터 카드 옆 **"매칭"** 버튼으로 같은 설정 창을 열어 남은 자리를 검색에 공개할 수 있습니다. 같은 화면의 **"링크 복사"** 버튼으로 이 방에 바로 참가할 수 있는 링크를 클립보드에 복사해 다른 사람에게 전달할 수도 있습니다.

### 재모집

멀티플레이 런이 비정상 종료된 뒤 다시 모이는 기능입니다.

- **호스트**: 멀티플레이 메뉴의 (원래 있던) **"세이브로 호스트"** 버튼을 누르면 자동으로 검색 가능하게 열립니다. 참가자들에게 초대 링크를 따로 보낼 필요가 없습니다.
- **참가자**: 매칭 설정 창의 **"대기"** 버튼을 눌러두면, 호스트가 세이브를 다시 열자마자 자동으로 찾아서 접속됩니다. 원래 그 런에 있었던 사람만 실제로 들어갈 수 있습니다(세이브에 없는 사람은 자동으로 거부됨).
- 원래 인원이 다시 다 모이면 자동으로 레디(출발 준비) 상태가 되어 대기 없이 바로 이어집니다.

### 킥 / 밴

로비에서 각 플레이어 카드 옆에 버튼이 뜹니다.

- **호스트**: "킥"(그냥 내보내기) / "밴"(즉시 내보내고 밴 목록에 등록, 이후 그 사람과는 매칭에서 마주치지 않음)
- **게스트**: "밴 등록"(당장 내보낼 순 없지만, 이후 내 매칭에서 그 사람 제외)
- 도전 이력(지난 런 기록) 화면에서도 과거 동료를 밴 등록할 수 있습니다.
- 호스트에게 킥당하면 뜨는 팝업에서 바로 그 호스트를 밴 등록할 수 있는 버튼이 추가로 뜹니다.

밴 목록은 매칭 설정 창의 **"밴 목록"** 탭에서 확인/해제할 수 있습니다. 이 목록은 순전히 내 로컬 설정이며, 매칭 검색 시 밴한 사람이 호스트인 방은 아예 뜨지 않습니다.

### 모드 정보

매칭 설정 창의 **"모드 정보"** 탭에서 현재 설치된 모드 목록을 확인할 수 있습니다. 여기 뜨는 목록은 설치된 모드 전체가 아니라 **멀티플레이 매칭에 영향을 주는(게임플레이 관련) 모드만** 표시됩니다. 매칭은 항상 이 모드 목록이 완전히 일치하는 상대와만 이루어집니다(끌 수 없는 필수 조건).
