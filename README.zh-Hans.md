# sts2_matchmaker

一个为《Slay the Spire 2》多人模式添加**匹配(自动搜索/建房)、重新招募、踢出/封禁**功能的Mod。

> 本Mod被登记为不影响游戏玩法的Mod(`mod_manifest.json` 中的 `affects_gameplay: false`),所以**和没有安装这个Mod的人一起玩多人游戏完全没问题。**通过邀请链接直接加入等原有方式,不论是否安装本Mod都照常运作。不过"匹配(自动搜索)"这项功能本身,只有双方都安装了本Mod才能互相找到对方。

## 使用方法

### 匹配

在主菜单 → 多人游戏界面,按下新增的 **"匹配"** 按钮即可打开匹配设置窗口。

- **社群名称**: 只想和固定的圈子组队时使用。留空则可与任何人匹配。
- **语言**: 只与特定语言的用户匹配。选择"不限"则不筛选。
- **跑图类型**: 标准 / 每日 / 自定义。
- **苦难等级**: 想要的苦难等级。选择"不限"则可匹配任何不超过自己已通关最高苦难等级的房间。
- **人数**: 目标人数。仅在主匹配弹窗中可选择"不限"(因为有可能会成为房主,这与实际房间人数上限是分开运作的)。
- **允许作为主机**: 取消勾选后只会尝试加入,若找不到对象则持续等待,不会成为房主。

按右下角的确认(✓)按钮开始匹配。找到符合条件的房间会自动加入;若找不到且开启了"允许作为主机",则会自动开房。

在已经作为房主的房间里,也可以通过角色卡片旁的 **"匹配"** 按钮打开同样的设置窗口,把剩余名额公开给搜索。同一画面还有 **"复制链接"** 按钮,可以把能直接加入这个房间的链接复制到剪贴板,分享给其他人。

### 重新招募

多人游戏跑图异常中断后,重新集合的功能。

- **房主**: 按下多人游戏菜单中(原有的) **"从存档建房"** 按钮,会自动以可搜索状态开房,无需再单独给参与者发邀请链接。
- **参与者**: 在匹配设置窗口按下 **"等待"** 按钮后,房主一旦重新打开存档就会被自动找到并连接进入。只有原本就在那局跑图里的人才能真正加入(不在存档中的人会被自动拒绝)。
- 原本的成员全部重新集合后,会自动进入准备(可出发)状态,无需等待即可直接继续。

### 踢出 / 封禁

在房间里,每张玩家卡片旁边会出现按钮。

- **房主**: "踢出"(单纯请出房间) / "封禁"(立即请出并加入封禁名单,之后匹配时不会再遇到这个人)
- **访客**: "登记封禁"(暂时无法立即请出对方,但之后自己的匹配会排除这个人)
- 在挑战记录(过往跑图记录)界面,也可以对过去的队友登记封禁。
- 被房主踢出时弹出的提示框中,还会额外显示一个可以直接封禁该房主的按钮。

封禁名单可以在匹配设置窗口的 **"封禁名单"** 标签页中查看/解除。这个名单纯粹是本地设置,匹配搜索时,被你封禁的人担任房主的房间根本不会显示出来。

### Mod信息

在匹配设置窗口的 **"Mod信息"** 标签页,可以查看当前安装的Mod列表。这里显示的并非全部已安装的Mod,而只是**会影响多人匹配(与游戏玩法相关)的Mod**。匹配始终只会在这份Mod列表与对方完全一致时才会成立(这是无法关闭的必要条件)。
