# sts2_matchmaker

一個為《Slay the Spire 2》多人模式新增**配對(自動搜尋/建房)、重新招募、踢出/封鎖**功能的Mod。

> 本Mod被登記為不影響遊戲玩法的Mod(`mod_manifest.json` 中的 `affects_gameplay: false`),所以**和沒有安裝這個Mod的人一起玩多人遊戲完全沒問題。**透過邀請連結直接加入等原有方式,不論是否安裝本Mod都照常運作。不過「配對(自動搜尋)」這項功能本身,只有雙方都安裝了本Mod才能互相找到對方。

## 使用方法

### 配對

在主選單 → 多人遊戲畫面,按下新增的 **「配對」** 按鈕即可開啟配對設定視窗。

- **社群名稱**: 只想和固定的圈子組隊時使用。留空則可與任何人配對。
- **語言**: 只與特定語言的使用者配對。選擇「不限」則不篩選。
- **跑圖類型**: 標準 / 每日 / 自訂。
- **苦難等級**: 想要的苦難等級。選擇「不限」則可配對任何不超過自己已通關最高苦難等級的房間。
- **人數**: 目標人數。僅在主配對彈出視窗中可選擇「不限」(因為有可能會成為房主,這與實際房間人數上限是分開運作的)。
- **允許作為主機**: 取消勾選後只會嘗試加入,若找不到對象則持續等待,不會成為房主。

按右下角的確認(✓)按鈕開始配對。找到符合條件的房間會自動加入;若找不到且開啟了「允許作為主機」,則會自動開房。

在已經作為房主的房間裡,也可以透過角色卡片旁的 **「配對」** 按鈕開啟同樣的設定視窗,把剩餘名額公開給搜尋。同一畫面還有 **「複製連結」** 按鈕,可以把能直接加入這個房間的連結複製到剪貼簿,分享給其他人。

### 重新招募

多人遊戲跑圖異常中斷後,重新集合的功能。

- **房主**: 按下多人遊戲選單中(原有的) **「從存檔建房」** 按鈕,會自動以可搜尋狀態開房,不需要再另外給參與者發邀請連結。
- **參與者**: 在配對設定視窗按下 **「等待」** 按鈕後,房主一旦重新開啟存檔就會被自動找到並連線進入。只有原本就在那局跑圖裡的人才能真正加入(不在存檔中的人會被自動拒絕)。
- 原本的成員全部重新集合後,會自動進入準備(可出發)狀態,不需等待即可直接繼續。

### 踢出 / 封鎖

在房間裡,每張玩家卡片旁邊會出現按鈕。

- **房主**: 「踢出」(單純請出房間) / 「封鎖」(立即請出並加入封鎖名單,之後配對時不會再遇到這個人)
- **訪客**: 「登記封鎖」(暫時無法立即請出對方,但之後自己的配對會排除這個人)
- 在挑戰紀錄(過往跑圖紀錄)畫面,也可以對過去的隊友登記封鎖。
- 被房主踢出時彈出的提示框中,還會額外顯示一個可以直接封鎖該房主的按鈕。

封鎖名單可以在配對設定視窗的 **「封鎖名單」** 分頁中查看/解除。這個名單純粹是本地設定,配對搜尋時,被你封鎖的人擔任房主的房間根本不會顯示出來。

### Mod資訊

在配對設定視窗的 **「Mod資訊」** 分頁,可以查看目前安裝的Mod清單。這裡顯示的並非全部已安裝的Mod,而只是**會影響多人配對(與遊戲玩法相關)的Mod**。配對始終只會在這份Mod清單與對方完全一致時才會成立(這是無法關閉的必要條件)。
